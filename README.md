# うどん繁盛記

セルフうどん店のカウンターを一人で回す、3分間のタイムマネジメント・スコアアタックゲーム。
スマホ縦持ち対応。ブラウザで動作します（依存なし・単一HTML）。

## 遊び方
- 調理器具をタップして具を用意（釜=うどん／卵台／煮込み鍋=油揚げ／専用フライヤー3台=天ぷら／おにぎり台）
- 品が揃ったらカウンターのお客さんをタップで提供
- メニューごとに必要な工程が違う。連続提供でコンボボーナス
- S ランク条件: 売上 ¥13,000 以上＋離脱 0 人＋廃棄 1 品以下

## 技術
Canvas 2D の高精細ドット絵（手描きスプライト）、WebAudio によるチップチューン BGM と効果音、Web Speech API による客の音声。
